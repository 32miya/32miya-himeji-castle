# 姫路城さんぽ

世界遺産・国宝 姫路城（兵庫県姫路市）を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「松本城さんぽ」「大阪城さんぽ」と同じ仕組み）。

- 時代を切り替え（メニューの「時代」）: 現代 ⇄ 江戸時代（17〜18世紀ごろ）
- 現代: 大手門・桜門橋・三の丸広場、入城口、菱の門、三国堀、いの門・ろの門・はの門（姥が石）・にの門・ほの門、水の一門〜五門、天守の内庭、大天守（地階〜6階）、備前丸、上山里（お菊井戸）、帯郭（腹切丸）、西の丸・百間廊下・化粧櫓、千姫ぼたん園、動物園、好古園、家老屋敷跡公園、美術館・歴史博物館、護国神社、大手前通り、JR姫路駅（キャッスルビュー）
- 江戸時代: 桜門と桐二の門の枡形、三の丸の御居城（城主の御殿）と向御屋敷、備前丸の本丸御殿、中曲輪の武家屋敷、外曲輪の城下町（大手筋の商家・木戸・火の見櫓）、中ノ門・外京口門、三重の堀（内堀・中堀・外堀）と船場川。人物をタップすると話します
- 地形: 姫山（天守の丘）と鷺山（西の丸の丘）を高さのある地形で再現。曲輪は石垣（扇の勾配・算木積み）で段々に造成し、迷路のような登城道（坂・石段・門・土塀の鉄砲狭間）を歩いて天守まで上れます
- 連立式天守: 大天守（外観5重・内部6階・地下1階）と西・乾・東の小天守を、イ・ロ・ハ・ニの渡櫓で環状につなぐ。白漆喰総塗籠の壁、目地まで白い屋根、千鳥破風・唐破風
- 大天守の中: 地階（流し・厠）、東大柱・西大柱、各階の武具掛け、3・4階の石打棚、6階の長壁神社。江戸時代は武具や兵糧を納めた倉として再現
- 入れる建物: 現代＝大天守・百間廊下・化粧櫓・好古園の茶室 / 江戸＝大天守・本丸御殿・御居城の書院・化粧櫓（千姫の座敷）・町家・武家屋敷
- 時刻: 朝・昼・夕・夜（夜は天守のライトアップ）
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）

人物・調度品・襖絵の画像（assets/atlas0〜3, tiles）は「大阪城さんぽ」と共通です。

姫路城のために描き下ろした2D素材:
- assets/hime_stone / hime_stone_b … 石垣（刻印入り）とその凹凸
- assets/hime_roof / hime_roof_b … 本瓦葺きの屋根（目地を白く足したもの）
- assets/hime_wall … 土塀（丸・三角・四角の狭間）
- assets/hime_floor … 天守・御殿の板の間
- assets/hime_ground … 地面の砂利のつぶつぶ
- assets/atlas4 … 鯱・鬼瓦・懸魚・華頭窓・長壁神社・姥が石・武具掛け・長持・米俵・弾薬箱・桜・松・楠の切り抜き
建物の配置と寸法は簡略な再現で、実測値ではありません（城域の距離はおよそ7割に縮めています）。江戸時代の御殿や城下町は、絵図などをもとにした想像を交えた復元です。

## 公開

このフォルダの中身（index.html・assets/・.nojekyll）をGitHubリポジトリの直下に置き、GitHub Pages を有効にすると、スマホのブラウザで開けます。

## お城さんぽシリーズ共通
- 人物・旗・襖絵・床板・石垣などの素材は、シリーズ共通の `https://32miya.github.io/oshiro/common/assets/` から読み込みます（このリポジトリに同じ画像を置かない）。一覧と使い方は `32miya/32miya.github.io` の `oshiro/common/README.md`。
- 天守の窓は本当の開口にして、各階の中から外の景色が見えるようにする（シリーズ共通の作り）。
- index.html の末尾の `oshiro-portal:begin`〜`end` は「お城選びへ戻る」ボタンなので消さない。
